始継終

悖逆の機骸-始

エリア移動

  • エリアは時計回りに移動
  • Tは奇数PINへボスを誘導
  • 遠距離Dは偶数PINに集合
  • 近接DとHはできるだけボスへ寄る
これにより、線ギミックの位置を9割固定できます。

エリア移動タイミング

  • 100 → 4PT
  • 105 → 3PT
  • 110 → 2PT
  • 115 → 1PT
壁を越えると全体ダメージ＋デバフ付与雑魚。一斉に渡らず分かれて移動し、雑魚は集敵→処理。

頭割り

  • 回復阻害あり
  • 重ねず、3～4人ずつに分かれて受ける

線AOE

  • 線が付いた3人は紫オーブ上にAOEが重なるように立つ
  • 線AOEが来たらオーブから離れる

ハード以降：オーブ4つ

台形に配置される球を三角形のAOEに収めるよう注意。

本体＋分身 距離減衰

1回目：ボスから離れる → 2回目：分身から離れる

悖逆の機骸-継

床破壊攻撃

  • 1 → 2 → 3 PINの順番でまとめて処理
  • 基本は対象者が指定された床を使って処理
  • 【非推奨】処理に余裕がある人は、巨大AOEの対象になった際、処理のタイミングでジャンプして一度床外へ出て戻ることで、余分な床を壊さずに処理可能
ハード以降
  • 2番目の対象者は猶予時間が短い
  • 間に合わない場合は1PIN床処理時：サブ床3PIN ／ 2PIN床処理時：サブ床4PINを使用

ハード追加ギミック：広範囲AOE

  • 2名指定距離減衰攻撃
  • 2PIN側の床の角と4PIN角で処理

ゴーレム処理

  • MT：6 PINで待機
  • ST：対角（2PIN側）で待機
  • DH：6 PIN集合
6PINゴーレムを先落とし → その後通常処理へ。

悖逆の機骸-終

基本散開オーブ吹き飛ばし距離減衰地雷レーザー照射時間停止運動会

基本散開

  • T：左手前（銃前）
  • D/H：右手前（中央手前と右手前タイルの境目付近）
吹き飛ばし攻撃後、Tは奥中央へ移動。

オーブ吹き飛ばし

剛体無効

奥・手前それぞれに大きな玉が出現し、約1.5マス分の吹き飛ばしが発生。落下しないよう立ち位置を調整します。

吹き飛ばされる方向

方向入力をしていない場合、玉がある位置とは逆サイドへ吹き飛ばされます。

対策

  • 玉側へ寄る
  • または玉と逆側の端まで逃げる

距離減衰地雷

通常は3人対象。2回目は4人指定の可能性あり。

対象指定から約10～11秒後に地雷設置 → さらに約3秒後に起爆。

対策

対象者同士で多少重なってもいいので、確実に端まで運んで設置してから中央へ戻る。中途半端な位置に置かないことを優先。

レーザー照射

頭上に①・②・③が表示され、それぞれ2人1組。各組の2人のうち1人だけが正解のクリスタルに紐づいています。

一定時間後、安全地帯1マスを除く各床に持続致死ダメージ。安全地帯は数秒おきに切り替わります。

処理方法

安全地帯の順番は固定らしい？ため、現時点では図2の位置を基準に処理。
  • イージー：①
  • ハード：① → ②
  • ナイトメア：① → ② → ③

それぞれ約2秒ずつ間隔を空けてクリスタルへアクセス。

ハード以降

レーザー照射後にTバスター。Tは照射処理後、角へ移動して処理。

時間停止

時間停止中に表示された攻撃予兆を覚え、解除後に順番通り処理します。

事前に少し散開しておかないと予兆が重なって見えづらくなるので注意。
  • 頭割り
  • 距離減衰
  • 単体AoE

頭上のピンク色の小さな時計が1周すると攻撃発生。

処理位置

  • 頭割り：中央・ボス前で集合
  • 距離減衰：4つ角へ散開（Hはここでダメ減）
  • 単体AoE：中央付近で散開
頭割り → 距離減衰 → 単体AoE

基本は頭割り処理 → 終わり次第4方向へ散開 → 単体AoE処理。

13人以上：距離減衰対象者は頭割りに参加せず、最初から担当する角へ移動。

運動会ギミック

床が6マス → 9マスに変化。ボスが右側へ移動し、右から左へ雷攻撃を行います。雷はジャスト回避可能。

基本配置

  • T：左上
  • D/H：左下

HはTを回復するため中央列へ移動してもOK。ただし中央列には巨大レーザーも来るため必ず回避。

ナイトメア

ゴーレムの幻影が追加。距離減衰攻撃を行うため、出現位置からしっかり距離を取ります。

叩きつけ攻撃が終わったら運動会終了。

ナイトメアでは、このギミック終了後からHPバー横のギミック予告が表示されなくなります。以降は攻撃を見て対応。

その他ギミック

青キューブ

青いキューブで床1面を指定。指定された床から離れて回避。

ランダム攻撃

頭割り / 距離減衰 / 単体AoEのいずれか1種類がランダムで発生。メインギミック終了後も次の予兆を確認して対応してください。
