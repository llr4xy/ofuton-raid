悖逆の機骸・始

エリア移動 頭割り 線AoE 距離減衰 ナイトメア

エリア移動

エリアは時計回りに移動します。

基本配置

  • T：奇数PINへボスを誘導
  • 遠距離D / H：偶数PINに集合
  • 近接D / H：できるだけボスへ寄る
この配置を意識することで、線ギミックの出現位置をほぼ固定化できます。

エリア移動タイミング

エリアゲージに応じて、各PTが順番に隣のエリアへ移動します。

  • 100 → 4PT
  • 105 → 3PT
  • 110 → 2PT
  • 115 → 1PT

壁を越える際に全体ダメージ＋デバフ付与の雑魚が出現します。

  • 一斉に壁を越えず、PTごとに分かれて移動
  • 移動後に出現した雑魚は集敵 → 処理

移動時の雑魚について

ノーマルから出現するI型
  • プレイヤーに攻撃力低下デバフを付与
ナイトメアからV型が追加
  • こちらが与えるダメージを低下させるフィールドを展開
  • フィールドを展開されると火力が大きく落ちるため、V型の行動に特に注意
⚠️ ナイトメアではI型に加えてV型も出現します。

雑魚はバラけさせず、しっかり集敵して処理してください。特にV型には中断を入れて、与ダメージ低下フィールドの展開を阻止しましょう。

頭割り

頭割りには回復阻害があります。

  • 頭割り同士は重ねない
  • 3～4人ずつに分かれて受ける

線AoE

線が付いた3人で紫オーブを処理します。

  • 紫オーブの上にAoEが重なるように立つ
  • 線AoEが来るタイミングでオーブから離れる

ハード以降

オーブが4つ出現します。

4つすべてのオーブが三角形のAoE内に収まるように位置を調整してください。

ナイトメア追加

オーブの配置パターンに、これまでの台形に加えて「ひし形」が追加されます。

⚠️ 配置の形を確認して、台形・ひし形どちらの場合でも4つのオーブすべてを三角形AoE内に収めるように処理してください。

本体＋分身 距離減衰

距離減衰攻撃は時間差で2回連続で来ます。

  • 1回目 → ボス本体から離れる
  • 2回目 → 分身から離れる

1回目を処理したあとも止まらず、2回目の分身位置を確認してください。

ナイトメアでの注意点

ドーナツ3連

ドーナツ3連自体はノーマルから存在するギミックです。

ナイトメアでは、表示された予兆を見て安全地帯の順番を覚えておく必要があります。

  • 最初に予兆をしっかり確認
  • 安全地帯の順番を覚える
  • 予兆が消えた後も、覚えた順番通りに移動して処理

HP0％以降：回避フェーズ

⚠️ ナイトメアではボスのHPを0％にしても戦闘は終了しません。

HP0％以降は、攻撃を回避し続ける耐久フェーズに移行します。

回避フェーズの処理

フィールドにピザカット状の危険地帯と安全地帯が表示され、その範囲がルーレットのように回転します。

さらに、プレイヤー数名を対象とした広範囲AoEが繰り返し発生します。

  • 回転する安全地帯の位置を確認しながら移動
  • 広範囲AoEの対象者は、できるだけ中央寄りへ誘導
  • 安全地帯を潰さない位置でAoEを処理
  • AoE同士が重なって逃げ場を塞がないように注意
  • 広範囲AoEは繰り返し来るため、次の安全地帯も意識しながら処理
指定AoEを外周へ持っていくよりも、できるだけ中央寄りで処理することで安全地帯を残しやすく、事故を減らせます。
⚠️ HP0％＝討伐完了ではありません。
最後まで気を抜かず、回転する安全地帯を確認しながら、指定AoEで逃げ場を潰さないことを優先してください。

基本配置

1回目

※図1参照

2回目

※図2参照

2回目は配置が左右反転します。

  • ② → 中段右
  • ③ → 右上

  • ⑤ → 左上
  • ⑥ → 左下

注意：⑦は位置を説明するための図上の表記です。実戦では⑦PINは設置しません。

共通ギミック

床破壊攻撃

床破壊攻撃は、毎回前半2名 → 後半2名の順に対象になります。

1回目

  • 前半2名 → ①PIN
  • 後半2名 → ②PIN

2回目

  • 前半2名 → ③PIN
  • 後半2名 → ④PIN
  • 床の残りが厳しい場合 → ⑤の床も使用可能

床を節約する方法 ※非推奨

処理に余裕がある人は、巨大AoEの対象になった際、着弾タイミングに合わせてジャンプで一度床外へ出て戻ることで、余分な床を壊さずに処理できます。

※失敗リスクがあるため、基本は指定されたPINの床を使用してください。

ハード以降

後半2名は処理までの猶予時間が短くなるため注意してください。

大きいメテオの処理

2回目の大きいメテオ対象者は、基本的に③の床を使用して処理します。

ただし、戦闘の進行状況によってボスによる床破壊が激しい場合は⑤の床を使用してもOKです。

  • 基本 → ③の床を使用
  • 床の残りが厳しい場合 → ⑤の床も使用可能

床の残り状況を確認しながら処理してください。

2回目の床処理

2回目は通常の床破壊処理に加えて、⑥PIN側と⑦表記の床も使用します。

これにより、中央の2枚の床をできるだけ残すように処理してください。

床が壊れた時の注意

床が破壊されても、約1秒ほど透明な床が残っています。

床が消えたように見えても、すぐに落下するわけではありません。

焦らず安全な床へ移動し、ジャンプすることで落下を回避できます。

ポイント：床が壊れても慌てず、移動＋ジャンプを意識してください。

ボス中心 距離減衰攻撃

ボスを中心に距離減衰攻撃が発生します。

この攻撃と同時に、ひびが入っている床が破壊されます。

  • 耐久に不安がある人は、ボスからしっかり離れて処理
  • 近接は、耐久に余裕があればロールのダメージ軽減を使用しながら殴り続けることも可能
  • 状況・PT構成・自身の耐久に合わせて判断
※Hはこのタイミングでダメージ軽減やシールドを入れてあげてください。

縦長AoE攻撃

縦長のAoEが移動する攻撃です。

移動パターンは以下の2種類です。

  • 外側 → 内側
  • 内側 → 外側

耐久に不安がある場合は、無理をせず回避してください。

近接は状況やPT構成に合わせて、ダメージ軽減を使用しながら殴り続ける対応も可能です。

ハード追加ギミック

広範囲距離減衰AoE地雷

2名を対象とした広範囲の距離減衰攻撃です。

対象者は、残っている床の角へ移動 → 地雷を設置 → 元の位置へ戻るという流れで処理します。

2人の対象者は、できるだけ離れた角で処理してください。

※念のため、ここでもHはダメージ軽減を入れてあげてください。

ゴーレム処理

1回目：待機位置

  • MT → ⑥PIN
  • ST → MTの対角となる角へ移動
  • D / H → ⑥PIN集合

1回目：処理順

⑥PIN側のゴーレムを先に撃破します。

ゴーレムを分散して削るのではなく、集中攻撃で先に1体倒すことが重要です。

※2回目はこの配置・処理をそのまま左右反転して行います。

注意：床破壊攻撃時のAoEは即死です。必ず避けてください。

ゴーレムフェーズ：キューブ攻撃

ゴーレムフェーズ中に、ボスがキューブを床へ放つ攻撃を行います。

攻撃前にボス側へ予告が表示されるため、余裕がある場合は確認しておくと回避しやすくなります。

攻撃パターン

  • 4つの角
  • 上下左右の4方向

どちらのパターンでも、中央の1マスは共通して安全地帯になります。

この攻撃は距離減衰攻撃よりもダメージが高く、耐えるにはかなり大きなダメージ軽減が必要です。そのため、基本的には耐えようとせず、必ず回避してください。

ゴーレムフェーズ終了後

ゴーレムフェーズを無事に突破すると、破壊されていた床が復活します。

ナイトメア追加：妨害ロボット

※図3参照

ナイトメアでは、①・②・③側から妨害ロボットが追加されます。

ロボットは出現後、図の矢印方向へ右方向に直進します。

※2回目は配置が左右反転するため、ロボットの進行方向も左右反転します。

ロボットの攻撃

ロボットは移動しながら定期的に範囲攻撃を行います。

さらに最終的には爆発し、寂滅がない場合は即死するため注意してください。

また、ロボットの円範囲爆発は床にもダメージが入ります。

床の残り状況にも影響するため、ロボットを止める位置には十分注意してください。

ロボットの止め方

ロボットの周囲にある円形範囲内にプレイヤーが入ると、ロボットの進行が停止します。

基本的に停止役はST（サブタンク）が担当します。

STの停止位置

※図3参照

  • ①側ロボ → ①床の右側境目
  • ②側ロボ → ②床の右側境目

それぞれ、落下しないギリギリの右側境界までロボットを進ませてから停止させます。

早い位置で止めると使用できる床を圧迫するため、できるだけ境目ギリギリまで進ませてから円範囲内へ入るようにしてください。

2回目

2回目は配置が左右反転するため、ロボットの進行方向・停止位置もすべて左右反転して処理します。

ナイトメア追加：HP0％以降「悪あがき」

ナイトメアでは、ボスのHPを0％にしても戦闘は終了しません。

HPを0％にすると、回避を続ける「悪あがきフェーズ」に移行します。

この間、ボス本体は上空を飛んでいるだけで何もしてきません。

悪あがきフェーズを4回耐えるとクリアです。

ゴーレム分身：突進攻撃

ゴーレムの分身が出現し、対象へ直線AoEを表示した後、その方向へ突進してきます。

重要：突進AoEだけでなく、ゴーレム分身本体にも攻撃判定があります。

分身そのものに触れないように注意してください。

寂滅がない場合は、タンクでも死亡する威力があります。

ただし、突進AoEは床1枚全体を覆うほどの広さではありません。

そのため、AoEの範囲外であれば、分身と同じ床にいても問題ありません。

個人対象：床破壊レールガン

各プレイヤーを対象に、床を破壊するレールガンが落ちてきます。

Tについては、レールガン自体のダメージは比較的余裕をもって耐えられる想定です。

ただし床を破壊するため、バラバラに処理すると使用できる床が一気になくなります。

悪あがきフェーズの基本処理

基本は、突進AoEとゴーレム分身を避けながら、全員で1枚の床へまとまってレールガンを処理します。

処理の流れ

  1. 全員でできるだけ同じ床へ集合
  2. 個人対象レールガンを同じ床にまとめて処理
  3. 次の床へ移動
  4. 再び集合してレールガンを処理

この流れを繰り返し、床を1枚ずつ順番に使用します。

レールガンをバラけさせず、できるだけまとめて順番に床を壊していくことを意識してください。

同時に、ゴーレム分身本体と突進AoEにも注意してください。

悪あがきフェーズ：クリアが厳しい場合

※どうしても通常処理が難しい場合のみ使用

PT1・PT2のT以外は全員床から飛び降りて死亡し、Tだけに残ってもらって回避します。

人数を減らすことで、レールガンが1セットだけになり処理が楽になります。

ただし、今後の3連戦を考えると、できるだけこの方法には頼らず通常処理で突破したいところです。

連戦モード・チャレンジでギミック緩和を使う場合

上記のギミック緩和を使用する場合、ギミック担当のTはアルーナ装備必須です。

継クリア後

「終」へ移動した後に、アルーナを使用して倒れているメンバーを蘇生します。

手順

  1. 復活CDが残っている場合は、CDが明けるまで待つ
  2. アルーナで全員を蘇生
  3. 全員蘇生後も、再び蘇生CDが切れるまで約10分待機
  4. CD回復を確認してから次の戦闘を開始
重要：この手順を使用する場合、待機中は絶対にボスを攻撃しないでください。

全員の蘇生と復活CDの回復を確認してから戦闘を開始します。

悖逆の機骸-終

基本散開オーブ吹き飛ばし距離減衰地雷レーザー照射時間停止運動会

基本散開

  • T：左手前（銃前）
  • D/H：右手前
    • 中央手前と右手前タイルの境目付近
吹き飛ばし攻撃後、Tは奥中央へ移動。

オーブ吹き飛ばし

剛体無効

奥・手前それぞれに大きな玉が出現し、約1.5マス分の吹き飛ばし攻撃が発生します。落下しないように立ち位置を調整してください。

吹き飛ばされる方向

方向入力をしていない場合、玉がある位置とは逆サイドへ吹き飛ばされます。

対策

  • 玉側へ寄る
  • または玉と逆側の端まで逃げる

どちらかで落下を防ぎます。

距離減衰地雷

要所要所に挟まってくるギミックです。

通常は3人が対象。
※2回目は4人指定の可能性あり

対象指定から約10～11秒後に距離減衰地雷を設置 → さらに約3秒後に起爆します。

対策

地雷は設置した瞬間には爆発しません。

対象者同士で多少重なってもいいので、確実に端まで運んで設置してから中央へ戻る。

中途半端な位置に置かず、しっかり端まで運ぶことを優先してください。

レーザー照射

プレイヤーの頭上に数字が表示されます。

  • 1組目：2名
  • 2組目：2名
  • 3組目：2名

それぞれ2人1組のグループになっていますが、各グループの2人のうち1人だけが正解のクリスタルに紐づいています。

難易度が上がるごとに、処理するグループが1つずつ追加されます。

一定時間後、安全地帯1マスを除いた各床パネルに持続致死ダメージが発生。安全地帯となる床は数秒おきに切り替わります。

処理順

  • イージー：1組
  • ハード：1組 → 2組
  • ナイトメア：1組 → 2組 → 3組

それぞれ約2秒ずつ間隔を空けてクリスタルへアクセスしてください。

クリスタル処理・コール

対象者が自分で正解のクリスタルをインタラクトできた場合は、入力完了後にチャットで「k」とコールします。

対岸などに正解のクリスタルがあり、対象者本人がインタラクトできない場合は、以下の流れで処理します。

  1. ※図2参照で、正解のクリスタル番号を①～⑥でチャットにコール
  2. そのクリスタルの近くにいる人が代わりにインタラクト
  3. 入力できた人が「k」とコール
「k」が確認できてから、次の組のクリスタル処理へ進んでください。

ハード以降

レーザー照射後にTバスターが来ます。

Tバスター時の立ち位置は、最後のテレポート先によって左右が変わるため注意。

  • ボスがいる側：D/H
  • ボスと反対側：T

TはD/Hから離れるようにボスと反対側の角へ移動し、Tバスターを処理してください。

固定で左右を覚えるのではなく、「ボス側にD/H、その反対側にT」を基準に判断してください。

時間停止

時間が停止し、その間に攻撃予兆が表示されます。表示された予兆を覚え、時間停止解除後に順番通り処理します。

ギミック前にあらかじめ少し散開しておかないと、予兆が重なって見えづらくなるので注意。

出現する攻撃は以下の3種類です。

  • 頭割り
  • 距離減衰
  • 単体AoE

頭上に表示されるピンク色の小さな時計が1周すると攻撃発生。

処理位置

  • 頭割り：中央・ボス前で集合
  • 距離減衰：4つ角へ散開
    ※Hはここでダメ減を使用
  • 単体AoE：中央付近で散開

攻撃順

頭割り → 距離減衰 → 単体AoE

基本は、頭割り処理 → 終わり次第4方向へ散開 → 単体AoE処理という流れです。

13人以上のレイドの場合：距離減衰対象者は頭割りに参加せず、最初から担当する角へ移動してください。

運動会ギミック

床が6マス → 9マスに変化します。

ボスが右側へ移動し、右から左へ雷攻撃を行います。
※雷攻撃はジャスト回避可能

基本配置

  • T：左上
  • D/H：左下

基本はこの位置で雷攻撃を回避します。

HはTを回復するために中央列へ移動してもOKです。

ただし、雷攻撃時には中央列へ巨大レーザーも来るため、中央列にいる場合は必ずレーザーを回避してください。

ナイトメア

ナイトメアからはゴーレムの幻影が追加されます。ゴーレムは距離減衰攻撃を行うため、出現した位置からしっかり距離を取ります。

叩きつけ攻撃が終わったら運動会ギミック終了。

ナイトメアでは、このギミック終了後からHPバー横のギミック予告が表示されなくなります。以降は予告に頼らず、攻撃を見て対応してください。

その他ギミック

青キューブ

青いキューブで床1面を指定してくる攻撃。指定された床から離れて回避します。

ランダム攻撃

以下のうちいずれか1種類がランダムで発生します。

  • 頭割り
  • 距離減衰
  • 単体AoE

これらがメインギミックの合間にも挟まってくるため、各ギミック終了後も次の予兆を確認して対応してください。
